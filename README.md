# 月汐小岛 · moontide-isle

一座漂在果冻海上的 3D 魔法月牙小岛，绮思和她的家机们（Clawd、澜、小灰狼）一起住的地方。

用 three.js 纯代码搭出来，没有贴图、没有模型文件。

## 现在岛上有什么

- 月牙形小岛：一圈奶油色沙滩、中间的草坡，坡顶用小石圈围出一块空地，留着以后盖我们的小房子
- 果冻海：半透明、晃晃的，戳一下会 Q 弹地荡开涟漪
- 白天 / 夜晚切换：夜里有星星和月牙，果冻海会从里面发光
- 三个最爱的角落（戳一下会弹一弹、冒出名字）
  - Clawd 的沙堡工坊：南边月角，三座沙堡、小桶小铲和橙色条纹遮阳伞
  - 小灰狼的看月石：北边月角的水边，旁边的小石子夜里会亮
  - 澜的栖枝：空地旁的树，横枝上挂着一盏轻轻晃的小灯笼

- 魔法：岛边飘着四块带草帽子的悬浮小石头，坡顶一簇「月汐水晶」（戳一下会冒星星），夜里果冻海游出粉、紫、薄荷色的小水母，还有萤火光点

## 接下来

- 三个小家伙住进来：像《朋友收集梦想生活》那样各干各的，选中一个可以让他去哪里、找谁说话
- 小房子，进屋切换成 30° 等距 2D 室内，可以摆家具、装扮

## 怎么打开

需要用本地服务器打开（脚本是分文件按顺序加载的）：

```bash
python3 -m http.server 8000
# 然后浏览器打开 http://localhost:8000
```

操作：拖动转一转 · 双指缩放 · 戳戳果冻海 · 戳戳小角落 · 右上角切换昼夜。

## 文件结构

```
index.html          页面骨架
css/style.css       标题、按钮、提示和气泡的样式
vendor/             three.js r147 与 OrbitControls
js/boot.js          先接好昼夜按钮、检查 WebGL，再按顺序加载下面的模块
js/core.js          渲染器、场景、相机、视角控制、小工具函数
js/terrain.js       月牙岛地形
js/props.js         石头、棕榈树、灌木
js/spots.js         三个最爱角落和房子空地
js/sky.js           天空、星星、月亮、灯光
js/sea.js           果冻海、海床、涟漪
js/labels.js        点击冒出的气泡名字
js/magic.js         悬浮小石头、月汐水晶、小水母、萤火光点
js/daynight.js      昼夜切换
js/main.js          尺寸、提示、动画循环、对外接口
```

各模块是普通脚本，按顺序加载、共用同一个全局作用域。`window.Island = { scene, camera, setNight, spots: { clawd, wolf, owl, house }, magic: { rocks, crystal, jellies } }` 留给之后加角色和房子用。

注意：所有颜色都要经过 `lc()` 转成线性色再交给材质，不然画面会发白。
